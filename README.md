## Purpose

This repository benchmarks the performance of standard RL algoriothms in various environments. A short description of the environemtns used in the sub-directories can be found below.

| Version | Environments |
| --------| ------------ |
| 1.0     | `CartPole-v1`, `Acrobot-v1`, `MountainCar-v0`, `MountainCarContinuous-v0`, `Pendulum-v1` |
| 1.1     | `LunarLander-v3`, `LunarLanderContinuous-v3`, `BipedalWalker-v3`|
| 1.2     | `Swimmer-v5`, `Hopper-v5`, `Walker2d-v5`, `HalfCheetah-v5`, `Ant-v5`, `Humanoid-v5`|

More details can be found in the `README.md` files inside each subdirectories.
